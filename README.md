# Dr Donald Hlahla website

Live site: https://dhlahlawebsite.netlify.app

- `index.html`: the page. Content lives in the `SITE` block at the top of the script.
- `photo.jpg`: hero portrait.
- `img/`: photos (gallery, book covers, pricing cards).
- `logos/`: organisation logos.
- Every push to `main` deploys automatically on Netlify.
- Forms (registration, booking, contact, article-access, proof-of-payment) are captured by Netlify Forms.

## Swap a photo
Upload a file with exactly the same name into `img/` or `logos/` and commit. It goes live in about a minute.
Keep photos under ~500 KB; lowercase names with hyphens, no spaces.
